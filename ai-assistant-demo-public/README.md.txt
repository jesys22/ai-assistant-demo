# AI-помощник менеджера (прототип)

Прототип AI-помощника для менеджера, который принимает обращение клиента, сверяется с короткой базой знаний и выдаёт два блока:
1. Вежливый ответ клиенту.
2. Подсказка по допродаже для менеджера.

## Стек

- **n8n** — оркестрация workflow
- **LM Studio + Phi-3 (14B)** — локальная LLM через OpenAI-compatible API
- **Python + HTML/JS** — UI (чистый HTML без фреймворков)
- **Docker** — для запуска n8n (опционально)

## Архитектура

Клиент (HTML) → Webhook n8n → 2 параллельных HTTP Request → Phi-3 (LM Studio)
↓
Code (сбор JSON)
↓
Respond to Webhook
↓
UI (чат + панель)

## Как запустить

1. Запустить LM Studio, загрузить модель `phi-line_14b`, включить локальный сервер на порту 1234.
2. Импортировать `workflow.json` в n8n (или использовать свой инстанс).
3. Опубликовать workflow (Publish → Active).
4. Открыть `index.html` в браузере (двойным кликом или через `python -m http.server 8000`).
5. Задать вопрос: «Сколько стоит доставка в Казань?»
